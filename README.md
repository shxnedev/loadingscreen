**Clean Responsive UI.** Minimalist frontend built with vanilla JavaScript, HTML5, and CSS3. Adapts dynamically to any aspect ratio—scales cleanly from standard 1080p to 4K ultrawide displays without stretching or clipped assets.

**Dynamic Background Rotation.** Lightweight slideshow cycling through high-resolution backgrounds (`background1`–`background3`) with hardware-accelerated CSS fades. Zero frame drops or render spikes while streaming visual assets.

**Native FiveM NUI Handshake.** Hooked directly into official loading events (`loadProgress`, `initFunctionInvoking`). Tracks real-time cache building, map downloads, and player initialization with accurate visual feedback—no fake progress timers.

**Zero Resource Overhead.** Extremely lightweight footprint on client memory. Fast DOM load times, zero memory leaks, and negligible CPU impact during the initial join pipeline.

**Fully Standalone.** 100% framework-agnostic. Drop-in ready for ESX, QBCore, Qbox, or custom standalone setups without external dependencies.
